# Chamilo Mobile (2.x)

Mobile client for [Chamilo LMS](https://github.com/chamilo/chamilo-lms) 2.0+.
Built with Vue 3 + Capacitor; consumes the platform REST/GraphQL API.

The `2.x` branch is a **fresh start** (orphan branch). The legacy 1.x
Cordova/Backbone app remains available on the `1.x` branch of this repository
and at https://github.com/chamilo/mobile — reference only.
